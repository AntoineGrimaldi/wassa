# wassa

- an autoencoder to detect spiking motifs
- using the Earth Mover's Distance (EMD) as a reconstruction loss leads to better retrieval of spiking patterns with limited number of recording
- EMD-trained autoencoders are more robust to temporal jitter on training data and MSE-trained ones are more robust to additive Poisson noise
- generative decoding on the allen institute dataset with temporal sequences
